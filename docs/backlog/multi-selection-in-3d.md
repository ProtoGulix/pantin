# Multi-selection in the 3D view

Phase: 8. ADR: 0055, 0040 point 9.

Left out of ADR 0055, 2026-10-18. Grouping selects several rows in the tree
only (Ctrl+click, Shift+click). Selecting several bodies in the 3D view would
need a rule that does not collide with the click-to-go-down navigation of
ADR 0040 point 9.
