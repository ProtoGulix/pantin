# Environment lighting for PBR materials

Phase: debt (on hold). ADR: 0053.

Put on hold by the user on 2026-09-29. Committing an environment binary to the
repository is not wanted (size, licence). If dull rendering becomes a real
problem, prefer a free HDRI loaded from a CDN (licence checked) or an
environment generated by code, never a versioned binary.

Waits on it: a metallic look for CAD colours named as metals ("Acier -
Satiné"). The STEP converter makes every material matte and non metallic on
purpose (`packages/step-converter`, `glb_materials.py`), since metal renders
dark without an environment. Moved here from the nested assemblies note
(2026-10-20); its other item, the axis from geometry, is done by ADR 0041.
