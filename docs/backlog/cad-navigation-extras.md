# CAD navigation extras

Phase: 8 (editing). ADR: 0036, 0035.

## Why

Left out of ADR 0036 (CAD navigation and standard views).

## What

- Touch and touchpad: the SolidWorks and ZW3D presets bind mouse buttons only,
  so a touchscreen no longer rotates, and the camera distance set each frame
  cancels Babylon's pinch zoom. Add a "touchpad" preset if asked.
- Free (trackball) rotation and roll (SolidWorks Alt + middle drag,
  Alt + arrows): need a camera of our own.
